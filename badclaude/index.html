Escolha onde trabalhar

Desktop e CLI são interfaces distintas do BadClaude. Os recursos disponíveis dependem da licença.

BadClaude Desktop

Abra o chat, componha imagens na estação Create e trabalhe com voz em português na estação Voice. A interface visual de criação começa no Studio.

BadClaude CLI

Use prompts para revisar texto, criar código e trabalhar nos arquivos do seu projeto pelo terminal. O Essencial inclui a CLI com a chave do seu provedor.
