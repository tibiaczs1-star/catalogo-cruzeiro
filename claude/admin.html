Instalação: copie os quatro .bat para C:\badclaudio (a pasta já existe) e de dois cliques. O bridge lê chaves.json local; nunca suba esse arquivo para o Git.

BadClaudio Diag — recuperação via Omniroute

Quando todos os canais do bridge caírem, o Diag abre o Claude Code roteado pelo Omniroute (gateway local compatível, http://127.0.0.1:20128). O próprio bridge já tenta o Omniroute automaticamente como fallback; o Diag é a rota manual quando nem o bridge subir.

Comando equivalente no terminal:

set ANTHROPIC_BASE_URL=http://127.0.0.1:20128 && claude
