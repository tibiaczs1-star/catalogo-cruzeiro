# Prompts ChatGPT Imagem — PubPaid 3.0

Use no Chrome com ChatGPT Imagem quando controlável. Todos os gráficos finais deste projeto devem sair do GPT Imagem: intro, exterior, interior, HUDs, menus, personagens, sprites, mesas, props, FX e overlays. Não usar outro gerador como arte final; se o Chrome/ChatGPT Imagem não estiver controlável, preparar prompts/arquivos e parar.

## 1. Exterior do bar
Create a premium pixel-art cinematic exterior of a small Brazilian Amazon bar in Cruzeiro do Sul at night, rainy asphalt, neon green sign reading "CZS Barzinho", warm wooden facade, motorcycles parked outside, subtle traffic lights, deep parallax layers, high contrast, 16-bit pixel art with modern lighting, no text except the sign, transparent-safe composition, game background, 16:9.

## 2. Interior/lobby
Create a premium pixel-art interior lobby for a Brazilian Amazon bar, dark wooden tables, pool table, checkers/chess corner, small stage, neon green HUD-like lighting, 10 visible seat positions for online players, cozy but competitive atmosphere, deep shadows, cinematic rim light, 16-bit pixel art with modern game UI readability, 16:9.

## 3. HUD principal
Create a transparent game HUD overlay for a premium pixel-art online bar game, neon green and gold accents, wallet/status panels, player seat list for 10 players, chat/emote dock, compact mobile landscape readability, Brazilian bar aesthetic, no placeholder text, separated UI elements, transparent background.

## 4. Personagens 10 personas
Create a sprite-sheet style lineup of 10 original Brazilian Amazon bar-game personas, diverse outfits and silhouettes, pixel art, full body, front-facing idle pose, transparent background, consistent scale, readable at small size, no real person likeness, no copyrighted characters.

## 5. Mesa de sinuca
Create a top-down premium pixel-art pool table for a Brazilian bar game, green felt, dark wood, realistic pockets, subtle neon rim light, cue ball and numbered balls separated and readable, game asset, transparent background plus optional shadow layer.
